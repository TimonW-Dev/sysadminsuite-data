# SysAdminSuite - Central Data Repository

Central data repository for sysadminsuite.com / TimonW-Dev.github.io. Stores automated JSON data updated via GitHub Actions.

## Structure

Every dataset lives in its own folder below `data/`. It is generated by a script in `scripts/` and refreshed by a workflow in `.github/workflows/`, which can also be started manually (`workflow_dispatch`).

```
data/<dataset>/...
scripts/<script>.py
.github/workflows/<workflow>.yml
```

Large datasets are split into small JSON files (shards), so the frontend only loads the part it needs.

## Datasets

| Dataset | Path | Description | Source |
|:--------|:-----|:------------|:-------|
| MAC vendors | `data/mac-vendors/<xx>.json` | MAC prefix to vendor name, sharded by the first two hex characters | [OUI Master Database](https://github.com/Ringmast4r/OUI-Master-Database) |

Further datasets are added as additional rows.

### Example: MAC vendors

Each shard (`00.json` … `ff.json`) maps a lowercase hex prefix (no separators) to a value, for example:

```json
{"3c01ef":"Sony","3c5ab4":"Google","3c2eff":"Apple"}
```

## Usage in JavaScript (GitHub CDN)

Every file is served via `raw.githubusercontent.com`:

```
https://raw.githubusercontent.com/TimonW-Dev/sysadminsuite-data/main/<path-to-file>
```

For example, to look up a vendor in the MAC vendors dataset:

```js
const BASE = "https://raw.githubusercontent.com/TimonW-Dev/sysadminsuite-data/main";

async function lookupVendor(mac) {
  const hex = mac.toLowerCase().replace(/[^0-9a-f]/g, "");
  if (hex.length < 6) return null;

  const response = await fetch(`${BASE}/data/mac-vendors/${hex.slice(0, 2)}.json`);
  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  const shard = await response.json();

  // Longest assignment first (9, 7 and 6 hex characters)
  for (const length of [9, 7, 6]) {
    const vendor = shard[hex.slice(0, length)];
    if (vendor) return vendor;
  }
  return null;
}

lookupVendor("3C:5A:B4:12:34:56").then(console.log);
```

## Sources and licensing

The data is derived from publicly available sources, for example the public IEEE registries and community projects built on them. Only the data needed by the frontend is stored here. Please refer to the linked source of each dataset for its original license and attribution.

```sh
python scripts/shard_mac_data.py
```
